```dart
    if (firestoreTotal > 0) {
      final localTotal = await getTotalStars(uid);
      
      // Agar Firestore'dagi ko'proq bo'lsa, uni ishlatamiz

}
```

```dart
/// Teil bo'yicha natijalarni guruhlaymiz (Lesen/Hören uchun)
Map<String, List<Map<String, dynamic>>> _groupByTeil(List<Map<String, dynamic>> results) {
  final grouped = <String, List<Map<String, dynamic>>>{};
  
  for (final r in results) {
    final title = r['title'] as String? ?? '';
    
    // Teil'ni aniqlash: "Teil 1", "Teil 2" va h.k.
    String teil = 'Boshqa'; // Default
    
    // Regex bilan Teil'ni topish
    final teilMatch = RegExp(r'Teil\s*(\d+)', caseSensitive: false).firstMatch(title);
    if (teilMatch != null) {
      teil = 'Teil ${teilMatch.group(1)}';
    } else if (title.toLowerCase().contains('lesen') || title.toLowerCase().contains('hören')) {
      teil = 'Umumiy';
    }
    
    grouped.putIfAbsent(teil, () => []);
    grouped[teil]!.add(r);
  }
  
  return grouped;
}
```

## ✅ 17. Firestore WhereIn Limit - 32 Student Muammosi

**Muammo:** Student home screen'da top 3 peshqadamlar ko'rinmasdi. Xatolik:
```
❌ 'in' filters support a maximum of 30 elements in the value [Iterable]
🔍 Student IDs in group: 32
```

**Sabab:** Firestore'da `whereIn` query maksimum **30 ta** element qabul qiladi, lekin guruhda **32 ta student** bor edi.

**Yechim:** Studentlarni 30 tadan bo'lib-bo'lib query qilish:

```dart
// Avval - bitta query (32 ta student bilan ishlamaydi)
.where(FieldPath.documentId, whereIn: studentIds)  // ❌ 32 > 30

// Endi - batch query (har 30 tadan)
for (int i = 0; i < studentIds.length; i += 30) {
  final batch = studentIds.sublist(i, min(i + 30, studentIds.length));
  // Har batch uchun alohida query
}
```

### Batching Logikasi:

1. **1-30 students:** Bitta query
2. **31-60 students:** Ikkita query (30 + 1-30)
3. **61-90 students:** Uchta query (30 + 30 + 1-30)

### Console'da Ko'rinishi:

```
🔍 Student IDs in group: 32
🔍 Fetching batch 1: 30 students
🔍 Fetching batch 2: 2 students
🔍 Total students fetched: 32
✅ Final student count: 32
```

**Fayllar o'zgartirildi:**
- `lib/services/firebase_service.dart` - `getGroupLeaderboardStream()` batching qo'shildi

**Natija:** 
- ✅ 30+ studentli guruhlar uchun ishlaydi
